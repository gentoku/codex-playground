# Gravity Lab · Explorer Edition

**[公開アプリを開く →](https://gentoku.github.io/codex-playground/)**

## 概要

Gravity Labは、重力と軌道力学を直感的に探索できるインタラクティブなWebアプリケーションです。ブラウザ上で天体を動かし、位置や速度を変えながら、軌道が生まれるしくみを観察できます。

- **宇宙探索室**：最大24天体の相互重力を2D・3Dでシミュレーション。太陽系、地球と月、連星、彗星、共鳴、重力アシストのプリセットを用意し、天体の追加・編集、カメラ追跡、軌道要素や保存量の確認、実験の保存・読み込みに対応しています。
- **地球周回ラボ**：人工衛星の高度・初速度・方向を操作し、円軌道・楕円軌道・衝突・脱出を実験。速度ベクトルのドラッグ、解析的な予測軌道、飛行中の速度変更（Δv）を通じて、軌道の変化を確かめられます。

バックエンドやアカウント登録は不要です。React・TypeScript・Vite・Three.jsを使用し、物理モデルの近似や初期条件の出典はアプリ内に表示しています。
