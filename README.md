# Gravity Lab · Explorer Edition

重力・軌道力学を、自分で動かして探索するブラウザ実験室。太陽系、連星、彗星から、地球のまわりの衛星まで。React / TypeScript / Vite / Three.js、バックエンド・アカウント不要です。

**公開先**：https://gentoku.github.io/codex-playground/ （この開発ブランチの変更はmainにマージするまで公開されません）

## 起動・検証

Node.js 22以上。

```bash
npm ci
npm run dev
```

http://localhost:5173/codex-playground/ を開きます。

```bash
npm test          # 物理計算と保存形式の自動テスト
npm run build    # TypeScript検査 + 本番ビルド
npm run preview  # http://localhost:4173/codex-playground/
```

実ブラウザ検証は別ターミナルでサーバーを起動した状態で実行します。

```bash
npx playwright install chromium
APP_URL=http://localhost:4173/codex-playground/ npm run test:browser
```

既存Chromiumを使う場合は `CHROMIUM_PATH=/usr/bin/chromium` も指定します。探索室と従来の地球周回ラボの両方を操作し、`work/` に検証用スクリーンショットを保存します。WebGLのテストは実際にChromiumを起動します（描画APIのモックではありません）。CIではソフトウェア描画を使用するため、実GPUの全機種での性能を保証するものではありません。

## 2つの実験室

### 宇宙探索室 · N-body / 3D

- 最大24天体の3次元相互重力。質量0の試験粒子も使用可能。
- 7つの実験：太陽系8惑星、内惑星、地球と月、連星と惑星、傾斜した彗星軌道、2:1共鳴、重力アシスト。
- 3Dの回転・移動・ズーム・天体選択・天体追跡。2Dでは同じ3D計算のXY投影を表示。
- 天体の追加・削除、名前・色・質量・物理半径・XYZ位置・XYZ速度の編集。
- 任意の3次元Δv、再生・一時停止・リセット・時間倍率・最大積分刻みの変更。
- 実軌跡、瞬間接触軌道、軌道面、速度方向、重力加速度方向、基準面、ラベルを切り替え。
- 相対距離・相対速度・近点／遠点距離・離心率・傾斜角・周期、慣性系のXYZ状態量。
- エネルギーと角運動量の保存量モニター。
- ブラウザ保存12件、JSON書き出し・読み込み。読み込み時にバージョン・有限値・範囲・IDを検証。
- 実験ごとの観察ガイド、初期条件の出典、計算モデルの説明。

### 地球周回ラボ · Classic / 2D

Phase 1を維持しています。固定・球対称の地球と衛星の二体問題、初期高度・速度・方向、マウス初速度設定、円／楕円／衝突／脱出プリセット、解析的予測軌道、地表衝突停止、Δv、ズーム・移動が利用できます。詳細は [地球周回ラボの説明](docs/earth-lab.md) を参照してください。

## 探索室の操作

1. 上のプリセットを選び、「再生」。速度は「日/秒」「時間/秒」など実際に進むシミュレーション時間で指定します。
2. 左ドラッグで回転、右ドラッグで移動、ホイールでズーム。2Dは左ドラッグで移動します。
3. 画面の天体・ラベル、または天体リストから選択。「選択へ寄る」で基準天体までの距離に応じて接近し追跡、「照準」ボタンで追跡を切り替え、「重心へ」で初期重心の広域視点に戻ります。
4. 「測定」で基準天体を選べます。表示する軌道要素はその基準天体との相対状態から計算します。距離は**中心間距離**であり高度ではありません。
5. 「編集」は一時停止します。変更を適用するとその時点の状態を置き換え、保存量の比較基準を更新します。位置はAU／km、速度とΔvはkm/s、質量はkg、物理半径はkm。
6. 天体追加は選択天体の近くに小さな衛星を作ります。状態の変更とΔvは慣性系XYZ成分で入力します。Z成分を変えると面外運動を作れます。
7. 「保存」で名前を付けて保存、またはJSONを書き出せます。保存はその時点の状態を記録します。「現在をリセット先にする」は同じセッションのリセット先だけを変更します。

プリセット変更・リセット・実験室切替・ページ再読み込みでは未保存の状態を失います。残したい実験は先に保存してください。ブラウザ保存は同じブラウザ・同じオリジン内のみ。データ消去やプライベートモードでは失われるため、長期保管・共有はJSONを利用してください。読み込み後は保存した時点が新しいリセット先になります。カメラ、表示切替、過去の軌跡、元プリセットの出典は保存ファイルに含みません。

### 観察のヒント

- **公転速度**：内惑星で水星と地球の周期を比べる。
- **共通重心**：地球と月で地球を追跡する場合と、重心から見る場合を比べる。
- **軌道傾斜**：彗星を3Dで回転させ、2Dの投影だけでは見えない面の違いを確認する。
- **共鳴**：2:1プリセットで、内側小惑星と木星の周期の比、長期の軌道要素の変化を追う。全共鳴周期の再現を保証するデモではありません。
- **重力アシスト**：最初は木星付近の追跡視点です。探査機の太陽基準と木星基準の速度を比較し、木星の前後を通るよう初期位置を変えてみる。惑星も動くため、系全体の保存量と探査機単独のエネルギーは別物です。

## 物理モデルと精度

### 相互重力

`src/physics/nbody.ts` は描画から独立した純粋な関数群です。右手系3D、内部はSI単位。

```
a_i = Σ(j ≠ i) G m_j (r_j − r_i) / |r_j − r_i|³
```

各ペアを一度計算し、互いの加速度へ反映します。質量0の粒子は重力を受けますが、他天体に力を与えません。重力計算では点質量、接触判定では設定した物理半径の球として扱います。力の軟化（softening）は使用しません。

**Velocity Verlet法**を使用。画面の再生速度は積分する時間量を変え、許容される時間刻みを大きくしません。最大刻みを上限として、ペアごとの自由落下時間尺度の1.5%と通過時間尺度の2%以下に短縮します。1フレーム最大700ステップ、壁時計のフレーム差は0.08秒までです。予算を超えた分を大きな刻みで消化せず実際の進行を遅くし、負荷制限を表示します。非表示タブでは自動で一時停止します。

固定刻みでは2次精度のシンプレクティック法ですが、状態に依存した刻み短縮を使う区間では厳密なシンプレクティック性はありません。これは誤差許容値を保証する適応積分器ではなく、教育的な近接遭遇の安全策です。最大刻みを小さくして保存量の収束を確認してください。非常に長い時間、極端な離心率、密集系を精密研究する用途には適しません。

### 衝突と異常状態

各ステップの相対移動線分と2天体の半径の和で接触を判定し、**そのステップを採用せず直前の状態で停止**します。衝突時刻・接触点の精密求解、合体・反発・破砕は行いません。初期から重なっている場合も停止します。必要刻みが1μs未満、または非有限値が発生した場合も状態を保って停止します。

### 保存量

質量を持つ全天体の運動エネルギーKとペアの重力位置エネルギーUを合計します。エネルギー変動は `(E−E₀)/(K₀+|U₀|)`、角運動量変動は `|L−L₀| / Σ mᵢ|rᵢ×vᵢ|₀`。ゼロ分母は「—」。編集・Δv・削除・追加・読み込み・リセットで比較基準を更新します。質量0の粒子は全系保存量に寄与しないため、粒子自身の誤差検証には別途相対軌道の収束確認が必要です。

### 軌道要素と表示

選択した天体と基準天体の相対状態、`μ=G(m₁+m₂)` から二体の接触軌道を計算します。**破線はその瞬間の二体近似であり、N体の将来予測ではありません**。支配的な重力源がある場合は他の天体の接触軌道も薄い実線で表示します。実際に積分した軌跡は各天体色の比較的明るい線です。

非束縛軌道の遠点と周期は未定義のため「—」。角運動量ゼロの径方向運動は傾斜角と軌道面を未定義にし、円錐曲線を描きません。傾斜角はXY平面基準です。軌道面は選んだ2天体の瞬間の角運動量方向に合わせます。

天体の**表示半径は画面上で見えるよう拡大**しています。速度・重力矢印は**方向を示す正規化した矢印**で、大きさの比較用ではありません。数値は測定パネルで確認してください。基準グリッドは初期XY面。2Dへの切替は物理計算のZを消さず、投影だけを変えます。

## 初期条件・定数の出典

- G = 6.67430 × 10⁻¹¹ m³ kg⁻¹ s⁻²：[CODATA 2018 / NIST](https://physics.nist.gov/cgi-bin/cuu/Value?bg)。
- AU = 149,597,870,700 m（定義値）：[IAU 2012 Resolution B2](https://www.iau.org/static/resolutions/IAU2012_English.pdf)。
- 太陽系・内惑星：[JPL Approximate Positions of the Planets](https://ssd.jpl.nasa.gov/planets/approx_pos.html)、1800–2050表のT=0。基準時刻は **J2000.0（2000-01-01 12:00 TDB）**、J2000黄道・春分点を基準とした太陽中心ケプラー要素から位置・速度を計算し、その後系全体の初期重心・運動量を除去します。地球の要素は元表では地球–月重心です。
- 質量・平均半径はNASAの[Planetary Fact Sheet](https://nssdc.gsfc.nasa.gov/planetary/factsheet/)相当の丸めた標準値、太陽質量1.98847 × 10³⁰ kg、半径695,700 km。丸めた質量とGを使うため精密なGM暦とは一致しません。
- 初期化後はN体積分。現在日時を表すものではなく、JPL HorizonsやDE暦を置き換えません。
- 地球と月・連星・共鳴・探査機・彗星は**教育用の合成条件**。彗星は実在天体ではありません。各プリセットの画面下に使用条件を明記しています。彗星シーンの太陽・木星のみJ2000近似を流用します。
- 従来の地球周回ラボはWGS 84 GMと平均地球半径を使います。N体モードと定数の丸め方が異なるため、微小な差があります。

## 制約

- ニュートン重力のみ。相対論、大気抵抗、放射圧、自転、扁平率、潮汐、有限時間噴射、燃料消費は未実装です。
- CPUでO(N²)、最大24天体。数千天体用のBarnes–Hut法やGPU積分、精密暦、長期安定性の自動判定、共鳴角の自動解析はありません。
- 実軌跡は天体あたり最大1,800点の移動履歴。一定の物理時間間隔を保証せず、表示負荷を抑えるため間引きます。過去の全履歴や将来のN体軌道の先読みは保持しません。
- 接触軌道は240分割、極端に遠方の部分を打ち切ります。最接近を精密に予測する道具ではありません。
- 3DにはWebGL 2対応のブラウザが必要。利用不可なら説明を表示し、WebGL不要の地球周回ラボが使えます。
- 初期重心を原点にした慣性系です。編集やΔvによって全系運動量が変わると重心は移動します。「重心へ」は初期原点への視点リセットです。
- JSONは最大256 KB、1〜24天体、質量0〜10³⁵ kg、位置各成分±10¹⁶ m、速度各成分±10⁸ m/sなどを検証します。計算可能範囲の上限であり、ニュートン近似が物理的に妥当な範囲を意味しません。
- デスクトップChrome/Chromiumを主に検証。レイアウトは390〜1920pxを確認します。iOS/Safari・FirefoxおよびすべてのGPUでの実機検証は未実施です。

```
src/
  App.tsx                  実験室切替・3Dモジュール遅延読み込み
  EarthLab.tsx             従来の地球周回ラボ
  components/OrbitView.tsx  従来のCanvas 2D描画
  physics/
    orbit.ts               固定地球の二体問題
    nbody.ts               3D相互重力・積分・保存量・接触軌道
    presets.ts             初期条件と観察ガイド
    *.test.ts              数値計算テスト
  lab/
    UniverseLab.tsx         実行ループ・状態管理・操作UI
    SpaceView.tsx           Three.js描画・カメラ・天体選択
    BodyEditor.tsx          天体編集フォーム
    storage.ts             バージョン付き保存形式と入力検証
    storage.test.ts         不正値・往復保存のテスト

```

物理状態にThree.js型を含めず、描画座標の縮尺も物理単位から分離しています。3D表示モジュールは遅延読み込みし、Three.jsのコアとレンダラーも独立したキャッシュ可能なチャンクに分離しています。

## GitHub PagesとCI

Viteのベースパスは `/codex-playground/`。既存の `.github/workflows/ci.yml` と `.github/workflows/pages.yml` を維持し、ブラウザ検証用ワークフローも追加しています。

- push / PR：物理・保存形式テスト、TypeScript検査、本番ビルド、別ワークフローでChromium操作検証。
- `main` へのpush：Pagesワークフローがテスト・ビルド後に `dist/` を公開。
- PagesのSourceは **GitHub Actions**。再公開は **Actions → Deploy Gravity Lab to GitHub Pages → Run workflow → main**。
- この開発ブランチはレビュー用です。**mainへのマージと本番公開はユーザーの確認後**に行います。
